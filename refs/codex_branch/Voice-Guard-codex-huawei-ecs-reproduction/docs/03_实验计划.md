> 与 01_方案思路.md 配套；本文件是**执行口径**，随结果更新。

## 1. 数据

- VCTK 22kHz 镜像（hf-mirror，110 人 / 44,455 句；缺 p235/p242 等部分人）
- 选定 20 位说话人：p225-p234、p236-p241、p243-p246
- 注册集（enrollment）：每人排序后前 30 句；测试集：第 30 句起（短句优先，见 §4）

## 2. 模型与评估栈

| 角色 | 组件 | 说明 |
|---|---|---|
| 被攻击 VC | AdaIN-VC 官方权重（NTU），24kHz / 512 mel | 白盒 |
| 攻击期身份判定 | AdaIN-VC Es 嵌入注册库（20×128）argmax | 忠实官方代码；已知对 20 人判别弱 |
| 评估 ASV-1 | ECAPA-TDNN（VoxCeleb 预训练）+ 20 人注册 | 强但跨域，clean-VC 筛选通过率可能低 |
| 评估 ASV-2 | **Es 嵌入 + 线性分类头**（VCTK 20 人训练） | 辅助诊断；与攻击共用特征空间，不等价于独立 GE2E |

## 3. 指标口径（已敲定）

- **MCD**：模型 mel 特征（不归一化，[0,1] 裁剪）逐帧 L2 均值 × 10√2/ln10
  （依据：论文 rec 行 MCD=0.00 只能在模型 mel 特征上得到；该口径量级与论文同档）。
  论文绝对量纲不可精确复现（未开源），只做方法间相对比较，报告中注明。
- **防御判定**（论文 Eq.9-11 的 ASV 部分）：
  F_imp: ASV(defended)==X；F_str: ASV(conv(defended))!=X；F_d = F_imp ∧ F_str。
- **筛选协议**（论文 Sec.5.3）：剔除 clean-VC 失败的样本
  （ASV(conv(clean))!=X 的句子不计入防御率），记录筛选通过率。
- MOS（MOSNet）/ WER（Whisper base）为 W3 严格指标（阈值 MOS_th=3, ASR_th=10%）。

## 4. 关键实验教训（已踩坑）

1. 单句攻击耗时随音频长度线性增长（1.2s 句 ~17min@3000+1500；4.3s 句 ~40min@800+400）。
   → 测试集**只选 1.5–2.5s 的短句**；主表用 1500/750 步，最终表择 3000/1500。
2. ECAPA 为主 ASV，Es 探头仅作辅助；筛选通过率必须单独报告，不因提高通过率而更换主评估器。
3. librosa 1.0 的 API 与 padding 变化已全部显式处理（H/θx/官方 inference shim）。
4. **掩蔽损失的 ε 依赖性（已验证）**：hinge 是软约束，ε=0.1（δ≈±0.2）时噪声远超 θx
   （均值高出 ~30 dB，loss_th 收敛慢）；ε=0.01 + c=8 + 1500 步时 loss_th 5.0 dB 且持续下降。
   → 论文的"强且不可感知"工作点在**较小 ε**；ε 扫描（T3）是展示"防御率—失真权衡曲线"
   的关键实验，不可省略。案例可视化（噪声藏于阈值下）应选小 ε 产物。
5. 攻击期 flag（Es argmax）判别弱 → c 二分常停 8（官方行为，如实报告）。

## 6. 加分项设计（W6）

**已出数据（VG@ε=0.05，exp03_eps005 信道扫描，见 channel_sim.csv）**：
- 原假设"压缩杀死扰动"仅部分成立：mp3/aac 对转换相似度几乎无影响（~0.1 不变）；
  电话信道（8k/G.711）双向分化——部分句子 conv 相似度回升（p227_044: 0.071→0.168，
  2.4×，扰动被削弱），另一部分反而转负（高频/内容损失使转换更不像 X）。
- **真正的脆弱点是 F_imp**：8k/G.711 使 defended 自身与 X 的相似度下降最多 0.16
  （p227_044: 0.447→0.284）——信道伤的是"被保护音频仍像本人"这一环。
- 结论（报告口径）：信道效应**句间异质、双向**；防御率的信道稳健性主要受
  F_imp 与 VC/ECAPA 脆弱性共同支配，而非单纯的"扰动被抹掉"。

VG vs EOT 在 {none, mp3-32k, g711} 上的 simX_def / simX_conv，看 EOT 能否
