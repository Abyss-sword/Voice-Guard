## ECS 启动与访问

在项目根目录，先完成下载、注册和预检，再安装服务：

```bash
bash deploy/install_platform_service.sh
curl http://127.0.0.1:8020/health
```

新 systemd 服务绑定 `127.0.0.1:8020`；完整模式 3000/1500，快速模式 300/200，
改进方法额外优化 1000 步。11 月 9 日安装成功，新版快速改进法真实请求及 6 个文件下载通过。
22.05 kHz 双声道上传经重采样处理，健康检查在计算期间耗时 0.078 秒。
该次干净转换筛选失败，正确返回非成功；不能把接口通过解释为防护质量达标。

Windows 新建 SSH 隧道（使用自己的实际私钥路径）：

```powershell
ssh -i "私钥路径" -N -L 8020:127.0.0.1:8020 -L 7860:127.0.0.1:7860 root@实例公网IP
```

本机课程前端使用 `http://127.0.0.1:8020/process`，与当前方法配置一致。
云端安全组不必公开 8020/7860。HTTPS 托管的公共前端仍需可访问的 HTTPS 后端；
本机隧道不等于已提供公开生产接口，验收电脑也需要隧道或另行配置 HTTPS。

## HTTP 契约

`POST /process` 是同步 multipart 请求：必填 `defend_audio`，可选 `adv_audio`，
`method_id=group_xx_voice_guard`，`parameters` 为 JSON 字符串。
参数为 `eps`、`fast_mode`、`target_speaker`、`method`、`preserve_context`，默认值见 JSON。
响应包含 `message`、5 个音频和 1 个报告共 6 个 artifacts，以及带身份判定的 meta。
结果通过 `/files/` 下载，允许跨域；`GET /health` 检查模型就绪。

身份判定要求 ASV 完整、干净转换正确识别目标。它不包含离线 MOS/WER，
`quality_evaluated=false` 时不能显示“质量达标”。自动说话人只是 20 人闭集匹配。
请求在 GPU 锁内串行执行，浏览器断开不保证 GPU 任务已经取消。
