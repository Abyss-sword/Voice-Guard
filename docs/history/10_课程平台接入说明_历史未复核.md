## 3. 适配服务（已实现的功能）

- `POST /process`：multipart 接收 `defend_audio`（必填）、`adv_audio`（可选）、`method_id`、`parameters`(JSON 字符串)
- 参数：`eps`（0.02–0.3，默认 0.05）、`fast_mode`（默认 true=300/200 步）、`target_speaker`（留空自动 ECAPA 识别）
- 响应：HTTP 200 + `{"message", "artifacts":[{kind,label,filename,url}×6], "meta":{...}}`
  产物：original / defended / delta / conv_clean / conv_defended / report.json，全部经 `/files/` 提供且允许跨域
- 失败：400/500 + `{"error":"..."}`（可读错误）
- `GET /health` 健康检查
- **实测**：`requests` 端到端跑通——defense_ok=True、defended 判 p225、转换后判 p238、6 产物全部 200

启动（本地）：

```powershell
.\.venv\Scripts\python.exe platform\service\adapter.py `
  --model-dir checkpoints\adain-vc-official `
  --registry outputs\registry.npz --attack-registry outputs\registry_vc.npz `
  --vctk data\VCTK22 --device cuda --host 0.0.0.0 --port 8020
```

## 5. 部署到华为云时接口地址怎么填

适配服务可与 Gradio 用同一台 ECS/云主机（见 `docs/07_部署操作手册.md`）：
`nohup python platform/service/adapter.py ... --host 0.0.0.0 --port 8020 &`，
安全组放行 8020，方法配置 endpoint 填 `http://<公网IP>:8020/process`。
平台前端在本地跑时（http://localhost:5173）可直接调 http 接口；若平台页面以 HTTPS 托管，
则需要给服务配 HTTPS（域名 + 证书）或由平台维护者说明。
