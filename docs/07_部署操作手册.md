# 华为云部署操作手册（需要你本人操作的部分）

> 我无法访问你的华为云账号，以下步骤由你在控制台完成（约 20–40 分钟）。
> 镜像与代码已就绪（`deploy/Dockerfile` + `frontend/app.py`）。

## 方案 A：ModelArts 自定义镜像在线服务（推荐，对应"部署到华为云平台"10 分）

### 第 1 步：把权重打进镜像（本机完成，我可以代跑）

```powershell
cd D:\Voice Guard
docker build -f deploy/Dockerfile -t voiceguard:latest .
```
> 若本机没有 Docker Desktop，也可以选择：ModelArts 训练作业/Notebook 里构建镜像。
> 替代：把 `checkpoints/`、`outputs/registry*.npz` 打包成 zip 上传 OBS，在容器启动脚本里下载。

### 第 2 步：推到 SWR（容器镜像服务）

1. 控制台搜索 **SWR**（容器镜像服务）→ 创建组织（如 `voiceguard`）。
2. 生成临时登录指令（SWR 页面上有"登录指令"按钮）→ 本机执行 `docker login ...`。
3. 推送：
   ```powershell
   docker tag voiceguard:latest swr.cn-north-4.myhuaweicloud.com/<组织>/voiceguard:latest
   docker push swr.cn-north-4.myhuaweicloud.com/<组织>/voiceguard:latest
   ```

### 第 3 步：创建 AI 应用

1. **ModelArts Studio / AI 应用管理** → 创建 AI 应用：
   - 名称：`voiceguard`
   - 元模型来源：**容器镜像** → 选第 2 步推的镜像
   - 容器调用接口：HTTP；端口 **7860**（部署健康检查：路径 `/`）
   - 运行环境调优：选 GPU 规格（`modelarts.vm.gpu.t4`，最便宜）
   - 其他默认 → 创建

### 第 4 步：部署在线服务

1. AI 应用列表 → 部署 → 在线服务：
   - 资源池：公共资源池；规格 T4 GPU
   - 实例数 1
   - 部署完成后拿到**服务地址**（http://xxx）
2. 浏览器打开服务地址 → Gradio 界面 → 上传音频一键保护（验收现场演示用这个地址）。

### 验收备用（服务偶发 5xx 时）

- 在线服务日志里看错误；常见问题：镜像太大冷启动慢（等 2–5 分钟）、健康检查端口不对。
- 切换"自定义健康检查"为 HTTP GET `/`，超时 60s。

## 方案 B：ECS + Docker（兜底，更可控）

1. ECS：Ubuntu 22.04，**GPU 实例**（T4/V100）或先用 CPU 实例演示（`--device cpu`，慢）。
2. 安全组放行 7860。
3. SSH 登录：
   ```bash
   sudo apt update && sudo apt install -y docker.io
   docker run -d --gpus all -p 7860:7860 voiceguard:latest   # GPU 实例
   # 或 CPU 演示：docker run -d -p 7860:7860 voiceguard:latest
   ```
4. 访问 `http://<公网IP>:7860`。
