建议配置：

| 项目 | 建议与核对点 |
|---|---|
| 区域 | 优先查看北京四 cn-north-4；以代金券、GPU 库存和配额为准 |
| 计费 | 按需计费、1 台；结算页核对代金券抵扣及额外现金支出 |
| GPU | NVIDIA CUDA GPU，显存至少 8GB，优先 16GB；如页面提供 T4 可考虑。不要选 Ascend/NPU |
| CPU/内存 | 建议 8 vCPU / 32GB；具体随 GPU 规格选择 |
| 系统 | Ubuntu 22.04 x86_64，优先带适配 NVIDIA 驱动的公共镜像 |
| 磁盘 | 至少 100GB 可用；数据压缩包 10.69GB，解压与 CUDA/Python/镜像还需空间 |
| 网络 | 一个公网 IP，按流量付费的低带宽起步；核对数据下载与公网流量计费 |
| 登录 | SSH 密钥对，本机保留私钥；不要提交进项目或发送密钥内容 |
| 安全组 | TCP 22 只允许本人公网 IP；使用 SSH 隧道访问网页，无需开放 7860 |

若 GPU 无库存或配额为 0，先申请配额或改区域。不要用 CPU 机器承诺完成正式批量攻击。
本轮无法从本机读取登录态或操作控制台，创建后提供公网 IP、SSH 用户名和本机私钥路径，
即可继续远程执行。用户名以镜像说明为准，常见为 root 或 ubuntu。

预算记录采用结算页实际数值：每小时有效支出约为 ECS + 磁盘 + 公网费用，
先预留至少 20% 余额，完成一条 benchmark 后再按预计总耗时安排实验。
`--max-hours` 只限制脚本运行时间，**不会停止 ECS 或结束云计费**。

## 2. 上传项目（本机 PowerShell）

在项目根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File deploy\package.ps1
# 替换私钥路径、用户名和公网IP；首次 SSH 应核对控制台显示的主机指纹
scp -i C:\keys\voiceguard.pem outputs\deploy\voiceguard-source.tar.gz ubuntu@公网IP:~/
ssh -i C:\keys\voiceguard.pem ubuntu@公网IP
```

在 ECS 上解包：

```bash
mkdir -p ~/voiceguard
tar -xzf ~/voiceguard-source.tar.gz -C ~/voiceguard
cd ~/voiceguard
bash deploy/ecs_bootstrap.sh
```

脚本核验 `nvidia-smi`，安装系统音频依赖、torch/torchaudio 2.5.1 CUDA 12.4 与固定版本前端栈，
输出 `outputs/cloud/runtime.json`。驱动需支持 CUDA 12.4；失败时先修驱动，不能以 CPU 冒充 GPU 验证。

## 3. 下载资源与构建注册库

推荐在 `tmux new -s voiceguard` 内执行，断开 SSH 后任务继续运行。

```bash
.venv/bin/python scripts/reproduce.py models --max-hours 2
.venv/bin/python scripts/reproduce.py data --max-hours 2
.venv/bin/python scripts/reproduce.py registry --max-hours 2
.venv/bin/python tools/preflight.py --scope experiment --out outputs/cloud/preflight.json
```

模型下载器采用官方 NTU AdaIN-VC 权重与固定提交 ECAPA，记录 URL、大小与 SHA256。
AdaIN 配置自动补齐官方 24kHz 预处理参数；VCTK 下载验证镜像提供的 SHA256，
自动整理为 `data/VCTK22/p225/p225_001.wav` 结构。大文件 curl 可断点续传。
没有公布校验值的模型仅记录本地摘要，不能称为已用官方摘要验真。

20 人名单：p225–p234、p236–p241、p243–p246；前 30 句注册，索引 30 起选测试句。
首次正式实验前保存所选文件列表；正式样本不足会报错，不静默缩小分母。

## 4. 冒烟、测时、正式实验

```bash
# 先查看计划，不下载/加载模型
.venv/bin/python scripts/reproduce.py main --dry-run
# 1 人 × 1 句，60/30 步，只验证执行链路
.venv/bin/python scripts/reproduce.py smoke --max-hours 1
# 1 人 × 1 句，3000/1500 步，测正式参数耗时
.venv/bin/python scripts/reproduce.py benchmark --max-hours 2
# 5 人 × 1 句 × 5 方法；根据 benchmark 和实际价格调整时间预算
.venv/bin/python scripts/reproduce.py main --max-hours 2
# 5 人 × 1 句 × 4 ε；独立阶段，余额允许再跑
.venv/bin/python scripts/reproduce.py eps --max-hours 2
.venv/bin/python tools/build_tables.py \
  --exp-dirs outputs/cloud/main_vg,outputs/cloud/main_vg-nop,outputs/cloud/main_emb,outputs/cloud/main_fb,outputs/cloud/main_e2e \
  --out outputs/cloud/results.md
```

默认 2 小时为每次调用上限，超时会中断当前子进程；重新执行同阶段可续跑已完成样本。
每句有独立种子，保存完整 WAV + result.json 才算完成；参数/权重变更时必须换目录。
CSV 同时报未筛选率、clean-VC 通过率和筛选后防御率，不把 clean-VC 已失败的样本算作有效防御。
结果目录分开记录 smoke 与 benchmark；冒烟成功不等同于论文结果复现。

上述主表是 **ECAPA 身份维复现**，不是论文全部指标的精确复刻。
Whisper/MOSNet 属额外评测，需安装评测依赖并下载对应权重。
`compute_wer.py` 默认要求 VCTK 文本；原始/被保护音频用目标文本，转换音频用内容源文本。
若镜像缺文本，可明确使用 `--reference-mode whisper`，结果必须标注为伪参考，不能称为真实转录 WER。
论文 ASR_th 与 WER 的映射未被代码充分验证，不将 ASV 成功率标注为联合质量约束成功率。
