# 人工听测（主观 MOS）操作手册

> 2026-11-09 建立。目的：用真人对保护音频打分，校核 MOSNet 预测（此前所有 MOS 均为模型预测，
> `docs/14`/`docs/15` 明确记录"真人 MOS 问卷尚未采集"）。

## 一、听测材料（已生成）

| 项 | 内容 |
|---|---|
| 句子 | 5 句（p225_040、p226_039、p227_044、p228_035、p229_033） |
| 条件 | 每句 3 段：**原始裁剪语音** / **VG ε=0.02** / **VG ε=0.05** |
| 总音频 | **15 段**（`outputs/listening/audio/`，约 41KB/段，24kHz） |
| 清单 | `outputs/listening/items.json`（页面读取） |
| 答案键 | `outputs/listening/answer-key.json`（**不发给听众**，用于事后解码 A/B/C→条件） |

生成命令（可换实验目录重建）：

```powershell
.\.venv\Scripts\python.exe tools\build_listening_items.py `
  --exp-dirs "outputs/exp03_eps002:epsilon=0.02,outputs/exp03_eps005:epsilon=0.05" `
  --out outputs/listening/items.json --key outputs/listening/answer-key.json --copy-audio
```

## 二、收集流程（5–10 人即可）

1. 启动页面：
   ```powershell
   .\.venv\Scripts\python.exe tools\listening_app.py `
     --items outputs/listening/items.json --out outputs/listening/results.jsonl --port 7861
   ```
2. 听众打开 **http://127.0.0.1:7861**（同一台电脑即可；如需远程，把 `--host` 改为 `0.0.0.0` 并自行保证网络安全）。
3. 页面对每句的 3 段做**随机 A/B/C 顺序**，听众：每段打 1–5 分（5=最自然/最像真原声）+ 选整体最愿意接受的一段；
4. 点"提交评分" → 追加写入 `outputs/listening/results.jsonl`（含每人的随机映射，可事后还原条件）。

> 注意：`show_api=False`，页面不暴露 API；每位听众独立会话、独立随机顺序。

## 三、统计

```powershell
.\.venv\Scripts\python.exe tools\summarize_listening.py `
  --results outputs/listening/results.jsonl --out outputs/listening/summary.json --md outputs/listening/summary.md
```

输出：各条件 MOS 均值/中位数/标准差/范围、整体偏好份额、逐句明细表（Markdown + JSON）。

> 工具链已用 2 条**模拟记录**验证（示例输出见 `example-results.jsonl` / `example-summary.md`，
> **不是真实评分，不得写入报告**）。真实收集后删除示例或改用新文件名。

## 四、报告写法（如实）

- 只报告"本批 N 位听众对这 15 段的偏好"；样本小，**不能外推**为总体 MOS；
- 若与 MOSNet 预测差距大，**以主观分为准**并如实报告差异；
- 若听众几乎总是偏好原始语音（预期如此，ε=0.05 噪声可闻），这本身是有价值的结论：
  说明"身份维通过但不满足不可感知"；与论文 4.07 MOS 的差距可直接写进局限性。
